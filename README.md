# Leaf Disease Prediction using CNN

A deep learning-based project that predicts plant leaf diseases from images using a Convolutional Neural Network (CNN).

## Features

- Upload a leaf image
- Image preprocessing
- CNN-based disease classification
- Data augmentation for better generalization
- Displays predicted disease and confidence
- Streamlit-based user interface

## Technologies Used

- Python
- TensorFlow / Keras
- CNN
- OpenCV
- NumPy
- Pandas
- Streamlit

## Project Workflow

Leaf Image
    ↓
Image Preprocessing
    ↓
Data Augmentation
    ↓
CNN Model
    ↓
Disease Classification
    ↓
Prediction

## Model

The CNN model consists of:

- Convolutional layers
- ReLU activation
- Max Pooling layers
- Flatten layer
- Dense layers
- Dropout
- Softmax output layer

## Dataset

The model is trained using a plant leaf disease image dataset.

## Installation

Clone the repository:

git clone YOUR_GITHUB_REPOSITORY_LINK

Install the required libraries:

pip install -r requirements.txt

## Run the Application

Run the Streamlit application:

streamlit run app.py

Then upload a leaf image to get the predicted disease.

## Results

The model is evaluated using accuracy, precision, recall and F1-score.
